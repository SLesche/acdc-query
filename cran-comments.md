## Patch
This is a minor patch adding functions to download databases which this package can interact with from their parent repositories. It provides functions to check the update status (check_ted() / check_acdc()), download the database or update existing databases (download_ted() / update_acdc()).

Also provides improved error handling for connecting to a database or when misspecifying column names.
